## Architecture

JSON translation files + DOM attribute-based application + CustomEvent for dynamic re-render.

| Component | Location | Purpose |
| --- | --- | --- |
| Translation files | `i18n/pt.json`, `i18n/en.json`, `i18n/es.json` | 101 leaf keys each, identical structure |
| I18n module | `js/i18n.js` | Detection, loading, application, switching |

## Flow

```text
DOMContentLoaded
│
├─ I18n.init()
│  ├─ detectLanguage()
│  │  ├─ localStorage('portfolio-lang') → if valid, use
│  │  ├─ navigator.language → map via LANG_MAP → if supported, use
│  │  └─ fallback: Settings.defaultLanguage ('pt')
│  │
│  ├─ loadTranslations(lang) → fetch i18n/{lang}.json → cache
│  ├─ applyToDOM()
│  │  ├─ [data-i18n] → el.textContent = translation
│  │  ├─ [data-i18n-html] → el.innerHTML = translation
│  │  ├─ [data-i18n-attr] → el.setAttribute(attr, translation)
│  │  └─ document.documentElement.lang = currentLang
│  ├─ updateLangSelector() → toggle .active on .lang-option
│  └─ updateSEO() → meta tags from Profile.meta[lang]
│
├─ [Home] Projects.init() → renders grid (English fallback)
├─ [Home] I18n.init().then(() → App.init()) → re-renders with translations
└─ [Generic] ProjectPage.init() → await I18n.init() → renders with translations
```

## Language switching

```text
User clicks .lang-option
│
├─ I18n.setLanguage(lang)
│  ├─ Load translations (cached after first load)
│  ├─ Store in localStorage
│  ├─ applyToDOM() → update static elements
│  ├─ updateLangSelector() → visual state
│  ├─ updateSEO() → meta tags
│  └─ dispatch CustomEvent('i18n:changed')
│
├─ [Home] App.renderDynamicContent() → re-renders skills, architecture, project grid
└─ [Generic] ProjectPage listener → updateSEO() + renderPage(project) + AnimationManager.init()
```

## Adding a new language

1. Create `i18n/{code}.json` — copy `en.json` as template, translate all 101 values
2. Add code to `Settings.supportedLanguages` in `config/settings.js`
3. Add entry to `Settings.languageLabels` (flag + label) and `Settings.languageNames` (full name)
4. Add `<li>` with `.lang-option[data-lang="{code}"]` to:
   - `index.html` (line ~98–106)
   - Each generic page nav (4 files)
5. Add `LANG_MAP` entry in `js/i18n.js` if browser sends a variant (e.g., `fr-CA` → `fr`)
6. Add `Profile.meta.{code}` in `config/profile.js` (title, description, keywords)
7. Update `og:locale` mapping in `js/i18n.js` `updateSEO()`

## DOM contract

| Attribute | Effect | Example |
| --- | --- | --- |
| `data-i18n="key"` | `textContent` = translation | `<span data-i18n="nav.projects">Projects</span>` |
| `data-i18n-html="key"` | `innerHTML` = translation | `<p data-i18n-html="about.paragraph1">...</p>` |
| `data-i18n-attr="a:k;b:k"` | `setAttribute(a, translation)` | `<input data-i18n-attr="placeholder:projects.searchPlaceholder">` |
| `i18n:changed` (event) | Triggers re-render | `document.addEventListener('i18n:changed', ...)` |
