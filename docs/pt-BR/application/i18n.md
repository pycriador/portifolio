## Arquitetura

Arquivos JSON de tradução + aplicação baseada em atributos DOM + CustomEvent para re-render dinâmico.

| Componente | Localização | Finalidade |
| --- | --- | --- |
| Arquivos de tradução | `i18n/pt.json`, `i18n/en.json`, `i18n/es.json` | 101 chaves folha cada, estrutura idêntica |
| Módulo I18n | `js/i18n.js` | Detecção, carregamento, aplicação, troca |

## Fluxo

```text
DOMContentLoaded
│
├─ I18n.init()
│  ├─ detectLanguage()
│  │  ├─ localStorage('portfolio-lang') → se válido, usa
│  │  ├─ navigator.language → mapeia via LANG_MAP → se suportado, usa
│  │  └─ fallback: Settings.defaultLanguage ('pt')
│  │
│  ├─ loadTranslations(lang) → fetch i18n/{lang}.json → cache
│  ├─ applyToDOM()
│  │  ├─ [data-i18n] → el.textContent = tradução
│  │  ├─ [data-i18n-html] → el.innerHTML = tradução
│  │  ├─ [data-i18n-attr] → el.setAttribute(attr, tradução)
│  │  └─ document.documentElement.lang = idiomaAtual
│  ├─ updateLangSelector() → toggle .active em .lang-option
│  └─ updateSEO() → meta tags de Profile.meta[lang]
│
├─ [Home] Projects.init() → renderiza grid (fallback inglês)
├─ [Home] I18n.init().then(() → App.init()) → re-renderiza com traduções
└─ [Genérico] ProjectPage.init() → await I18n.init() → renderiza com traduções
```

## Troca de idioma

```text
Usuário clica em .lang-option
│
├─ I18n.setLanguage(lang)
│  ├─ Carrega traduções (em cache após primeiro carregamento)
│  ├─ Armazena em localStorage
│  ├─ applyToDOM() → atualiza elementos estáticos
│  ├─ updateLangSelector() → estado visual
│  ├─ updateSEO() → meta tags
│  └─ dispara CustomEvent('i18n:changed')
│
├─ [Home] App.renderDynamicContent() → re-renderiza skills, architecture, grid de projetos
└─ [Genérico] ProjectPage listener → updateSEO() + renderPage(project) + AnimationManager.init()
```

## Adicionar um novo idioma

1. Criar `i18n/{code}.json` — copiar `en.json` como template, traduzir todos os 101 valores
2. Adicionar código a `Settings.supportedLanguages` em `config/settings.js`
3. Adicionar entrada em `Settings.languageLabels` (bandeira + label) e `Settings.languageNames` (nome completo)
4. Adicionar `<li>` com `.lang-option[data-lang="{code}"]` em:
   - `index.html` (linha ~98–106)
   - Nav de cada página genérica (4 arquivos)
5. Adicionar entrada `LANG_MAP` em `js/i18n.js` se o navegador enviar uma variante (ex.: `fr-CA` → `fr`)
6. Adicionar `Profile.meta.{code}` em `config/profile.js` (title, description, keywords)
7. Atualizar mapeamento `og:locale` em `js/i18n.js` função `updateSEO()`

## Contrato DOM

| Atributo | Efeito | Exemplo |
| --- | --- | --- |
| `data-i18n="chave"` | `textContent` = tradução | `<span data-i18n="nav.projects">Projects</span>` |
| `data-i18n-html="chave"` | `innerHTML` = tradução | `<p data-i18n-html="about.paragraph1">...</p>` |
| `data-i18n-attr="a:k;b:k"` | `setAttribute(a, tradução)` | `<input data-i18n-attr="placeholder:projects.searchPlaceholder">` |
| `i18n:changed` (evento) | Dispara re-render | `document.addEventListener('i18n:changed', ...)` |
